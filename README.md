The Weekly_info.yaml file is automatically generated by the program. Do not edit it manually.
It contains information about the last run of the program, such as how much weight was deleted and how many files were deleted. This file is used to keep track of the program's performance and to provide feedback to the user.
The logs will eventually Be deleted If Too old, if you want to save them somewere else, copy them to another location before they are deleted.

# IMPORTANT

if You want to delete infos about specific Folders you can put the Direct link in The list wich is containded in the Setting.yaml

If you want to disable temporarly some folders deletion you can simply Set the value found in the settings.yaml to the side of the Folder directory to False. My programm will do the rest.
If you want to Delete files wich are 10 days old you can change the setting from the Setting.yaml file.
If you do not want the rotation of the logs you can simply Set the variable Enabled under the Log rotation section to false in the settings.yaml file
